# Giriş sayfası görselleri

Tümü [Unsplash](https://unsplash.com) kaynaklıdır ve Unsplash Lisansı ile
gelir: ticari kullanım serbesttir, atıf zorunlu değildir.

| Dosya | Unsplash fotoğraf kimliği |
| --- | --- |
| `birebir-ders.webp` | `photo-1587323655395-b1c77a12c89a` |
| `renkli-bloklar.webp` | `photo-1575364289437-fb1479d52732` |
| `sanat-etkinligi.webp` | `photo-1560421683-6856ea585c78` |
| `oyun-terapisi.webp` | `photo-1495900593237-22dc861b231d` |

Kareler bilinçli olarak **tanınabilir yüz içermeyecek** şekilde seçildi (üstten
çekim, eller, kadraj dışında kalan yüzler). Unsplash Lisansı, tanınabilir
kişilerin ticari bir üründe kullanımı için ayrıca model izni (model release)
gerektirebiliyor; yüz göstermeyen kareler bu riski tamamen ortadan kaldırıyor.
Görselleri değiştirirken aynı ölçüte uyun.

Yeniden indirmek için:

```
curl -o birebir-ders.webp \
  "https://images.unsplash.com/photo-1587323655395-b1c77a12c89a?w=1400&q=72&fm=webp&fit=crop"
```
